## 표시와 갱신

기존 자산배분 요약카드 아래 독립 컨테이너 `#summary-forecasts`에 환율 A/B/C/컨센서스
4개 카드와 환헤지 A/B/C 3개 카드를 표시한다. 각 카드에는 네 지평을 모두 유지한다.
환헤지 시장은 UST/USD, JPY, AUD, GER/EUR 중 선택한다. 입력을 저장하거나 포트폴리오
비중을 변경하지 않으며, 요약카드 재진입·적용값 갱신 시 현재 게시값/적용값을 읽는다.
전망카드는 포트폴리오 Group 저장 묶음의 과거 스냅샷에 포함되지 않는다.

- 모형 지평: 각 모형 기준일 이후 3/6/9/12개월. 모형별 기준일·실제 목표일을 표시한다.
- 컨센서스: 서울 오늘 이후 네 달력 분기말. 입력 화면의 표시 분기 수와 무관하게 네 칸을 유지한다.
- FX 숫자는 원/달러 정수, 수익률·헤지비율·VaR는 % 소수 두 자리다. CSV는 원정밀도다.
- 목표일이 서울 오늘 이하이면 전망 수치를 숨기고 갱신 필요를 표시한다.
- 산출물·지평·필수 입력이 없으면 사유와 결측을 남긴다. 다른 모형으로 대체하지 않는다.
- 접힌 산출 기준에 정의·가정을 기록하며, 기본 화면은 수치 중심이다.

## 환율 산출 계약

| 모형 | 중심 | 불확실성 | VaR |
|---|---|---|---|
| A | 기존 Markov MC 평균, step 63/126/189/252 | 게시된 2.5/97.5% 분위수 | 달러 보유 원화 환손실 |
| B | 선택 학습창·선택 LSTM/XGB/앙상블의 직접 지평 전망 | 동일 조합의 기실현 로그 예측오차 24개 이상 경험 분위수 | 보정 하단을 이용 |
| C | 기존 축소추정 로그 중심, 직접 3/6/9/12개월 | 기존 기실현 과거오차 보정 구간 | 보정 하단을 이용 |
| 컨센서스 | 저장된 응답 평균 | 응답 간 모집단 표준편차 ±1σ, 최소 응답 2개 | 미산출 |

C는 9개월을 별도로 추정한다. 6/12개월 보간을 쓰지 않는다. 기존 1개월 전망을 유지해
전체 파이프라인 지평은 1/3/6/9/12개월이다. 이전 4지평 게시본도 화면에서 읽되 9개월은 비운다.
B는 선택 학습창의 최신 게시 기준일로 맞추며 다른 기준일의 전망을 섞지 않는다.
B 보정오차는 기준시점이 현재 전망보다 이전이고 실현 목표일이 현재 전망 기준일 이하인 행만 쓴다.
기존 UI의 평가기간/국면 선택으로 보정 표본을 사후 선택하지 않는다.

FX VaR 97.5% = max(0, 100 × (1 − 하단2.5% / 모형 기준 환율)).
금액 VaR가 아닌 미헤지 달러 포지션의 환손실률이며 채권 가격손실은 포함하지 않는다.
중앙 95% 구간의 하단은 단측 97.5% VaR에 대응한다. 단측 95%와 혼동하지 않는다.
0 하한은 이익인 분위수를 손실 없음으로 표시하는 관례이며 최대손실 보장이 아니다.
컨센서스 응답분산을 미래 환율손실 분포로 해석하지 않는다. CSV의 컨센서스 지평(개월)은
비우고 분기명·실제 목표일을 기록한다.

2026-10-31 조회한 기존 게시본의 B는 학습 산출물 미등록 상태였다. 러너 기본 지평은
1/3/6/9/12로 확장했지만 이번 작업에서 ML 학습이나 Data 쓰기는 수행하지 않았다.

## 환헤지 산출 계약

기존 `hedgeModelBCompute`의 검증된 공분산·금리·현재 HP 캐리와 B의 시장별 적용 가정을 재사용한다.
A는 기존 CIP 비교 화면의 미래예측이 아닌 **100% 헤지 참고안**, B는 기존 비용·위험
CE 최적화, C는 이번에 정의한 **최소분산 비교 기준**이다. C는 별도 학습한 예측모형이 아니다.
A는 제약 밖일 수도 있으므로 이를 표시한다. B/C 비율은 기존 헤지 하한·상한을 따른다.
수치가 나타내는 대상은 헤지비율과 그 비율 적용 후 누적 채권·FX 수익률이다.
환헤지 프리미엄 자체의 미래 예측 또는 헤지비율의 추정 신뢰구간을 표시하는 것은 아니다.

기간 T = 지평 개월 / 12일 때 누적 중심은 연 기대수익률 × T,
누적 변동성은 연 변동성 × sqrt(T), 중앙 95% 구간은 중심 ± 1.959963984540054 × 변동성이다.
환헤지 VaR97.5% = max(0, −95% 구간 하단)이다. 초기 원화 투자금 대비 총수익의 손실률이다.
HP 양수는 수취, 음수는 지불이며 공분산 내부 단위는 소수수익률 제곱이다.

현재 금리·캐리·공분산·예상 FX 변화·헤지비율을 고정한 선형 근사다. 시계열 자기상관,
모수 추정오차, 미래 헤지비용 변화, 거래비용, 볼록성·롤다운을 포함하지 않는다.
기본 예상 FX 변화 0은 예측모형 산출물이 아니다. 최소분산이 동률이면 비율을 비우며,
동률 비율별 평균도 달라지면 단일 수익분포를 표시하지 않는다.
