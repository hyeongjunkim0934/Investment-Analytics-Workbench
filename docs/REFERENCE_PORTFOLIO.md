# 레퍼런스 포트폴리오

자산배분의 포트폴리오·리스크연계 오른쪽에 비교 전용 화면을 둔다.
예시 고정비중과 사용자가 입력한 비중을 동일한 완료월 표본에서 비교한다.
산출물은 과거 실현수익률의 모멘트이며 CMA·미래 기대수익이나 투자 권고가 아니다.
입력은 기존 포트폴리오·리스크연계 설정을 변경하지 않는다.

## 데이터와 원화 환산

`pipeline/reference_portfolio.py`가 `data_bb*.xlsx`에서 파싱된 아래 원천만 읽어
`alloc.json.reference`를 구성한다. 대체 원천을 자동으로 채우지 않는다.

| 슬롯 | 원천 키 | 계산 기준 |
|---|---|---|
| kr_bond | bb:한국종합 | 원화 총수익지수 |
| us_bond | bb:미국종합 | USD 총수익지수 × 달러원 |
| kr_equity | bb:한국_KOSPI_TR | 원화 총수익지수 |
| us_equity | bb:미국_S&P500_TR | USD 총수익지수 × 달러원 |
| commodity | bb:S&P GSCI TR CME | USD 총수익지수 × 달러원 |

USD 자산은 환노출을 유지한다. 원천 지수와 `bb:달러원`이 모두 관측된 **동일 날짜**에
환산하며, 유효 자산 전체가 함께 관측된 날짜만 사용한다. 그 후 월별 마지막 관측을
선택한다. 미래 환율·다른 날짜의 마지막 환율·forward fill은 사용하지 않는다.

가용 원천 각각의 마지막 관측일 중 가장 이른 날짜를 `data_asof`로 기록한다.
그 날짜가 속한 달은 항상 제외한다. 마지막 관측이 달력 월말이어도 다음 달의 관측이
있기 전에는 완료로 인정하지 않는 보수적 규칙이다. `asof`는 실제 채택된 마지막
월말이며, 두 날짜를 구분해서 표시한다.

월 누락은 보존한 상태로 수익률을 계산하므로 다개월 변화가 한 달 수익률로
들어가지 않는다. 마지막 유효 수익률부터 역순으로 이어지는 **연속 공동 표본**만
사용하며, 최근 12·36·60·120개월을 각각 충족한 창만 게시한다. 충분하지 않은 창을
짧은 표본으로 대신하지 않는다. 현재 활용 가능한 자산들의 표본은 모든 비교안에 동일하다.

## 수치 정의

단순 월간 수익률을 사용한다. USD 자산의 원화 수익률은
\(r_{KRW,t}=(1+r_{USD,t})(1+r_{FX,t})-1\)이다.

연환산 산술평균은 \(12\bar r\), 연환산 공분산은 \(12\widehat{\mathrm{Cov}}(r)\),
연환산 변동성은 \(\sqrt{12}\,s(r)\)이다. 표본분산 분모는 \(n-1\)이다.
비중은 매월 목표비중으로 재조정한다고 가정한다. 비용·세금은 포함하지 않는다.

포트폴리오 평균은 \(w^\top\mu\), 분산은 \(w^\top\Sigma w\)이며,
위험 기여 비중은 \(w_i(\Sigma w)_i/(w^\top\Sigma w)\)이다.
분산이 0이면 위험 기여 비중과 Sharpe를 계산하지 않는다.
산술평균을 CAGR로 표시하지 않으며, 집계 모멘트로 복원할 수 없는 MDD·누적성과는 게시하지 않는다.

Sharpe의 대용금리는 `bb:한국_크레딧_CD_AAA_3m`이다. 각 수익률 월 직전 월의
마지막 CD(AAA) 3M 연율 금리(%)를 사용한다. 월간 대용수익률을 그 금리의 1/12로
근사하므로 연환산 대용금리는 해당 월별 금리의 평균이다. 이는 신용위험 없는 국채
수익률이나 실제 현금 전략의 총수익을 의미하지 않는다. 화면의 Sharpe는 평균 초과수익을 포트폴리오 변동성으로 나눈 근사치다. 시변 대용금리를 차감한 초과수익률 변동성을 분모로 사용하지 않는다. 동일 표본 전체에 전월 금리가
있을 때만 Sharpe를 제공하며 누락 시 0%로 대체하지 않는다.

## 원천 이상과 부분 가용성

모든 가격 수준은 유한한 양수여야 한다. 없는 원천·잘못된 수준·환율 부재는 해당
자산을 비활성화한다. 국내채권·미국채권이 최소 24개 겹치는 관측에서 전부 동일하고
값의 변화가 있으면 국내채권을 원천 검증 대기로 둔다. 서로 다른 표시통화의 독립
지수라고 검증되지 않은 복사본을 국내채권으로 사용하는 것을 막기 위한 검사다.

다섯 슬롯 순서는 고정한다. 비활성 자산의 평균·변동성·공분산 행과 열은 모두 null이다.
해당 자산에 양의 비중이 있는 비교안은 계산하지 않고 사유를 표시한다. 원자재 spot을
총수익지수 대신 사용하지 않는다. 0 비중 자산의 null은 계산 대상에서 명시적으로 제외한다.
유효 원천이 두 개 미만이거나 최근 연속 표본이 12개월 미만이면 전체 블록이 비활성이다.

## 2026-11-06 현재 파일 점검

사용자가 지정한 Drive `data_git/data_bb.xlsx`를 읽어 실제 산출을 검증했다.
수정일은 2026-11-05, 파일 SHA256은
`a8bb9c01041baa4da150063895e447406c02d6caaecff89e049e3b9823b8a44e`이다.
원본은 공개 저장소에 포함하지 않는다.

- 마지막 원천 관측은 2026-11-05, 사용한 마지막 완료월은 2026-10-31이다.
- `한국종합`과 `미국종합`은 겹치는 6,504개 관측 모두 일치했다. 원본 셀을 직접 읽는
  경로와 기존 파서 경로가 동일한 이상을 확인했다. 국내채권 슬롯은 비활성 처리한다.
- `S&P GSCI TR CME`는 없으며, `원자재지수 / SPGSCI INDEX / PX_LAST`만 있다.
  원자재 슬롯은 비활성 처리한다. spot으로 대체하지 않는다.
- 미국채권·국내주식·미국주식은 계산 가능하며 연속 공동 표본은 299개월이다.
  1·3·5·10년 창을 제공한다. 10년 창은 2016-11-30~2026-10-31이다.
- 원본의 `원화유동성`도 `달러유동성`과 겹치는 5,072개 관측 모두 같았다.
  레퍼런스 계산은 그 ETF 원천을 사용하지 않고 CD 대용금리를 별도로 사용한다.
- 확인한 GitHub Data 기본 브랜치의 원천은 다른 snapshot이다. 원본 워크북은 변경하지
  않고 이 기능에 한정된 검증 완료 집계 snapshot으로 현재 Drive 자료를 연결한다.
  다른 기존 모듈의 입력·산출은 그대로 유지한다. 아래 선택 규칙을 따른다.

## 현재 Drive 집계 snapshot과 배포 입력

Data 저장소 루트의 선택 파일 `reference_portfolio_snapshot.json`은
`source`와 `reference` 두 객체만 가진다. source에는 원본 이름
`data_git/data_bb.xlsx`, 수정시각(시간대 포함 ISO), 파일 SHA256을 기록하고,
reference에는 위에서 검증한 집계 블록만 넣는다. 원본 수준·수익률은 넣지 않는다.

`build_for_data_dir`는 먼저 기존 Data 원본으로 통계를 계산한다. 이후 snapshot의
정확한 필드·자산/원천/통화 매핑·연율 단위·모멘트와 부분 가용성 계약을 동일한
배포 게이트로 검사한다. snapshot의 `data_asof`가 더 최신인 경우에만 이 기능의
블록을 선택한다. 원본의 `data_asof`가 같거나 더 최신이면 원본 계산이 우선한다.
따라서 Data의 정상 갱신을 오래된 snapshot이 가리지 않는다.

snapshot을 채택하면 output의 `source_snapshot`에 출처 이름·수정시각·SHA256을
보존한다. 잘못된 snapshot은 경고를 남기고 기존 원본 계산으로 복귀한다. 루트의
정해진 파일만 읽으며 외부 경로/URL을 읽지 않고, Data 디렉터리 바깥을 가리키는
심볼릭 링크와 256KB 초과 파일도 거부한다. 이 파일은 원본 데이터의 오류를
정정하거나 기존 자산배분·리스크 모듈을 덮어쓰는 수단이 아니다.

## 계약과 검증

`process.py`는 기존 `alloc.port` 활성 여부와 관계없이 reference를 생성한다.
계산 예외도 명시적 비활성 블록으로 남긴다. `check_output.py`는 reference 존재,
자산 순서·null 보존·창 날짜와 길이·연율 단위·공분산 대칭/PSD·대용금리 결측 사유를 검사한다.
허용되지 않은 원본 시계열 필드는 게시를 거부한다.

`tests/test_reference_portfolio.py`는 직접 월간 P&L의 평균·분산으로 엔진 결과를
대조하고, 환산 항등식·달력 공백·부분월·날짜 불일치·누락 자산·중복 원천·12개월
경계·결측 대용금리·계약 변조를 검증한다. 이는 동일 원자료의 독립 계산 경로이지
독립 벤더 검증이나 미래 수익률 검증이 아니다.

현재 파일의 미국 60/40에 대해 별도 openpyxl 원본 셀 읽기와 표준 라이브러리 P&L
연산으로 10년 통계를 대조했다. 연 산술평균 11.5486282753%, 변동성
10.2133611981%, CD 대용금리 2.1670833333%, Sharpe 0.9185560718이며
게시 집계와 차이는 각각 1e-8 미만이다. 두 경로 모두 같은 원본을 사용한다.
