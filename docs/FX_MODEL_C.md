# 환율모형C — 금리차·모멘텀 축소추정

USDKRW의 월별 로그변화를 1·3·6·12개월별로 직접 추정한다. 금리차의 부호를
환율 방향으로 강제하지 않으며, UIP·CIP 항등식이나 구조적 위험프리미엄 분해로
해석하지 않는다. 기존 컨센서스, A(마코브), B(LSTM/XGBoost)는 유지한다.

## 입력과 시간

- 환율: `bb:달러원`. 유효 수준이 전혀 없을 때만 `info:USDKRW`로 명시 폴백한다.
- 금리: `info:한국_1y`, `info:UST1y`, 단위 연 %. 차이는 한국−미국 %p다.
- 유효한 실제 공통 날짜만 사용한다. 앞채움·보간·벤더 접합은 없다.
- 월말 마지막 평일에 환율·한미 금리 모두 실제 관측된 월만 사용한다. 그 날짜가
  휴일이거나 입력 하나라도 없으면 해당 월을 제외한다. 거래소 휴일 달력 보정,
  근접일 대체는 없다. 이후 관측이 추가되어도 과거 결측 월을 소급해서 되살리지 않는다.
- `asof`는 공통 호가일, `model_date`는 월말 마지막 평일의 의사결정일이다.
  이 버전은 두 날짜가 같아야 한다. 과거 예측·라벨 만기판정도 같은 날짜를 사용한다.
- 1·3개월 모멘텀과 h개월 타깃은 **달력 월 키**로 연결한다. 누락 월을 행 번호로
  압축하지 않는다. 월별 샘플링된 날짜와 일간 최신 시세를 혼용하지 않는다.

## 추정과 비교

설명변수는 한미 1년 금리차, 1개월 로그변화, 3개월 로그변화다. 학습 표본에서만
평균·모집단 표준편차로 표준화하고 상수 열은 0으로 처리한다.

\[
y_{t,h}=\log(S_{t+h}/S_t),\qquad
(\hat a_h,\hat b_h)=\arg\min_{a,b}\left\{N^{-1}\sum_{t\in\mathcal T}(y_{t,h}-a-z_t'b)^2+\lambda b'b\right\}.
\]

절편은 벌점에서 제외한다. \(\lambda=1\), 최소 60개·최대 최근 120개 실현 라벨,
축소비율 \(w=0.5\)는 고정 설계 가정이다. 평가자료로 재선택하지 않는다.

\[
\widehat y^C_{t,h}=0.5(\hat a_h+z_t'\hat b_h),\qquad
\widehat S^C_{t+h}=S_t\exp(\widehat y^C_{t,h}),\qquad
\widehat S^{RW}_{t+h}=S_t.
\]

C는 로그변화 예측을 RW의 0으로 절반 축소한 모형이다. 축소 전 ridge도 동일한
예측 기준일·대상일·실현값에서 함께 평가한다. 수준 점예측은 **로그 중심**이며
수준의 산술 기대값이나 엄밀한 조건부 중앙값이라는 주장은 하지 않는다.
기여도는 절편 및 세 표준화 변수의 로그변화 기여(%); 합계가 C의 예측 로그변화다.
인과 기여나 서로 독립인 경제 충격 분해가 아니다.

## 의사 표본 외 검증과 구간

각 월별 예측은 대상일이 그 예측 기준일 이하인 라벨만 학습한다. 미래의 피처
표준화, 라벨, 예측오차를 사용하지 않는다. 최신 데이터셋의 수정 이력·당시 공표
시각을 복원하지 않았으므로 진정한 실시간 빈티지 검증과 구별한다.

\[
e_{t,h}=\log(S_{t+h}/S_t)-\widehat y^C_{t,h},\qquad
I_{t,h}(q_1,q_2)=S_t\exp\!\left(\widehat y^C_{t,h}+[Q_{q_1}(e),Q_{q_2}(e)]\right).
\]

해당 예측일까지 실현된 동일 지평의 과거 OOS 오차가 24개 이상일 때만 구간을
만든다. 68%는 16/84 분위수, 95%는 2.5/97.5 분위수이며 선형 분위수 보간이다.
현재 점예측이 경험적 구간의 중앙이나 내부에 있어야 하는 것은 아니다.
적중률은 각 과거 예측시점에 이미 만들 수 있었던 구간만 평가한다.
최종 오차 전체로 과거 구간을 소급해서 만들지 않는다.

RMSE·MAE는 원/달러, Theil U는 C RMSE / RW RMSE다. RW 오차가 0이면 U는 비운다.
U<1은 해당 표본의 오차가 작다는 뜻이며 통계적 유의성이나 미래 우월성 보장이
아니다. 다개월 예측은 겹치며 N개 오차가 독립 관측이라는 해석은 부적절하다.
구간은 경험적 과거오차 범위로, 명목 68/95% 커버리지·정규성·모수 불확실성을
보장하지 않는다. 국면 변화, 빈티지, 데이터 스누핑 위험은 남는다.

## 구현·범위

`pipeline/fx_model_c.py` → `fx.json.model_c` → `dashboard/fx-model-c.js`.
자료 부족·수치 오류는 사유와 함께 비활성화한다. 15개 JSON 파일 계약은 유지한다.
공개 결과에는 전망·실현 환율·오차 통계·최신 예측 기여도·설정만 실으며 입력
금리·모멘텀의 전체 피처 행렬과 원본 XLSX는 커밋하지 않는다.

이번 `/hj-only`의 대상은 IAW이고 Data는 읽기만 수행했다. 두 허용 저장소에서
KG 본체·최근 정독 노트를 찾지 못했으므로 **KG 정독 논문을 직접 반영하거나
재현한 모형으로 표시하지 않는다**. 과거 대화의 P/Q·비생성 요인 논의를 곧바로
환율 예측식의 증명으로 사용하지 않는다. KG 원문 근거 연결은 미완료다.

검증은 엔진 경계조건, 별도 증강 최소제곱 경로 대조, 미래 데이터 교란 불변성,
월 누락·오차 만기·동일 평가 표본, 실제 JS 렌더/표/CSV, 배포 계약을 포함한다.
실데이터 검증은 Data 커밋 `a2f5c546`의 XLSX 원본으로 전체 파이프라인을 재빌드했다.
다운로드 파일의 Git blob SHA를 조회된 원본과 대조했다. 별도 openpyxl 열 추출에서
한국1Y 6,149개·UST1Y 4,316개·USDKRW 6,462개의 날짜·값이 생산 파서와 정확히 일치했다.
공통 일별 4,305개와 월말 마지막 평일 188개도 별도 달력 계산과 일치했다.
최종 모형 기준일은 2026-08-31이다. 별도 추출은 같은 XLSX·cached-value reader를
사용하므로 독립 벤더 대조·엑셀 재계산·빈티지 복원은 아니다.

기존 `fx.ts/outlook/markov/lstm_xgb` 산출물은 게시본과 동일하며 전체 산출물의
배포 게이트를 통과했다. 실제 C JSON을 JS 렌더·표·CSV 프로브에 넣어 검증했다.
브라우저 실행환경 오류로 실화면 시각검증은 미완료다. 초기 게시 축약자료 QA는
최종 원자료 검증과 구별하며 최종 성과를 바탕으로 λ·축소비율을 재선택하지 않았다.
