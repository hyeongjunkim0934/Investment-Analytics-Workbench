다른 프로젝트의 코드·자료·작업 이력은 사용하지 않는다.

## 입력과 산식

`hedge.json.bond_analytics[market].outlook`의 기존 공개 집계만 사용한다.
새 데이터 게시·파이프라인 재추정은 없다. 현재 10년 국채금리, 현재 HP
3M·6M·12M 평균, 동일일 월간 채권·환율 충격의 연율 공분산이 입력이다.
원본 수준·월별 수익률은 추가로 게시하지 않는다.

헤지비율을 h, 현지 채권수익을 b, 원화 표시 외화수익을 f, signed 헤지 캐리를 c로
정의한다. c는 양수 수취·음수 지불이다. y는 현재 국채금리, μFX는 사용자 시나리오다.
화면 연 % 입력은 100으로 나누고 아래 식은 모두 연 소수수익률로 계산한다.

\[
R(h)\approx b+(1-h)f+hc,\qquad
\mu(h)=y+(1-h)\mu_{FX}+hc.
\]

\[
V(h)=\Sigma_{bb}+2(1-h)\Sigma_{bf}+(1-h)^2\Sigma_{ff},\qquad
CE(h)=\mu(h)-\frac{\lambda}{2}V(h).
\]

FX 분산이 양수이면 다음 무제약 해를 사용자 하한·상한에 투영한다.

\[
h_{MV}=\operatorname{clip}\left(1+\frac{\Sigma_{bf}}{\Sigma_{ff}},h_{min},h_{max}\right),
\]

\[
h_{CE}=\operatorname{clip}\left(1+\frac{\Sigma_{bf}}{\Sigma_{ff}}
+\frac{c-\mu_{FX}}{\lambda\Sigma_{ff}},h_{min},h_{max}\right).
\]

최소분산은 고정 헤지비용과 무관하다. 비용 반영 비율은 지정한 λ·FX 시나리오 아래
CE 최대화 결과다. 기대수익이 큰 외화 보유와 위험 감소의 절충이며 예측 신호가 아니다.
현재 채권금리는 목적함수의 수준만 바꾸고 최적 헤지비율에는 영향을 주지 않는다.

- 기본 가정: λ=5, FX변화=0%, 현재 헤지비율=50%, 제약 0~100%.
- λ는 0 초과 100 이하, FX변화는 −50~50%, 헤지비율은 0~100%만 허용한다.
- 현재 비율은 실제 기관 보유값이 아닌 사용자 입력이다. 0·50·100% 및 현재 비율은
  제약 밖이어도 비교값으로 남기되 제약 충족 여부를 구분한다.
- 예상 FX 민감도는 적용한 가정에서 −2/−1/0/+1/+2%p 변경한 조건부 재계산이다.
- 모든 수치 표시는 소수 두 자리이며 CSV는 계산 정밀도를 유지한다.

## 수치·데이터 경계

`active:true`, 최소 36개 월간 표본, HP 원천·부호·연율, 공분산 labels와 단위를
확인한다. 결측을 0으로 대체하지 않는다. 공분산은 유한·2×2·대칭·양의 준정부호여야
한다. 기계 정밀도 내 Cauchy 경계 오차만 보정하며 실질적 비정상 행렬은 거절한다.

FX분산이 0이면 PSD 조건상 채권·FX 공분산도 0이다. 최소분산 해는 동률이며 하한을
계산상 대표값으로 삼는다. 비용 반영 해는 c>μFX이면 상한, c<μFX이면 하한,
c=μFX이면 동률이다. 하한=상한인 경우에는 가능한 비율이 하나뿐이다.

전액 헤지가 위험을 높일 수 있다. 예를 들어 채권·FX 분산이 각각 0.01,
공분산이 −0.009이면 최소분산 비율은 10%다. 무헤지 연 변동성은 약 4.47%,
전액헤지는 10.00%다. 위험감소를 음수까지 허용하며 강제로 양수화하지 않는다.

기존 파이프라인의 관측일 차이 7일·위험표본 종료 지연 62일·기준월 제외 조건을
그대로 따른다. 기준일은 데이터 관측일이며 오늘 날짜로 바꾸지 않는다.

## UI와 유지보수

- `dashboard/hedge-optimizer.js`: 순수 계산·입력 검증. 전역 함수와 CommonJS 제공.
- `dashboard/hedge-model-b.js` / `.css`: 시장 카드·입력·비교·차트·표·CSV.
- `app.js::renderHedge`: B 렌더 연결. `selectHedgeWorkspace`: B 표시 후 크기 복원.
- 입력은 적용 시 원자적으로 검증하며 오류가 있으면 기존 결과를 유지한다.
  시장별 가정은 브라우저 로컬에만 저장한다.
- 탭 전환은 모델을 재추정하지 않는다. 재렌더 시 B 소유 차트와 observer를 정리한다.
- Pseudo 환헤지 문서에 별도 절을 두어 정의·부호·단위·미반영 위험을 기록한다.

## 검증과 한계

합성 PSD 행렬의 해석해를 독립 격자 최적화·단위 변환·비용 방향·자연헤지 반례와
비교한다. UI는 실제 renderer와 이벤트를 실행해 입력 오류, 시장별 상태, 표·CSV,
탭 전환, 결측과 차트 수명주기를 검증한다.

이는 고정 현재 듀레이션으로 금리변화를 변환한 채권수익 근사다. 환율도 로그수익률을
1차 합산한다. 실제 총수익률·볼록성·롤다운·거래비용·선물 MTM·동적 재헤지를
포함하지 않는다. 현재 3개 HP 평균 고정은 1년 캐리 가정이며 정확한 선도계약
실현수익률 항등식이 아니다. λ와 FX 가정은 추정된 예측치가 아니다.

시장별 표본기간이 다르며 시장 간 공분산이 없으므로 통합 다통화 포트폴리오 최적화로
해석할 수 없다. OOS 성과·최적화의 투자 우월성·모수 불확실성은 검증하지 않았다.
KG 자료가 허용 범위에 제공되면 논문별 입력·식별·운용 시계에 맞춰 별도 확장한다.
